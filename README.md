# SWARS

**SWARS** is a simple **space shooter game** developed using the **Godot Engine**. This passion project was created as a personal exploration into game development, focusing on gameplay mechanics, scene management, and interactive design.  

Give it a try and enjoy the gameplay! Feedback and suggestions are welcome.  

## Features

- Classic 2D space shooter mechanics  
- Player-controlled spaceship with shooting capabilities  
- Enemy AI with dynamic movement and attacks  
- Bullet collision and scoring system  
- Restart and game state management  
- Modular scene structure for easy enhancements  

## Tech Stack

- **Engine:** Godot Engine  
- **Language:** GDScript  
- **Tools:** Git for version control, Docker (optional for reproducible environment)
